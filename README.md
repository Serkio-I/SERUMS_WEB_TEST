# SERUMS Bancos Medicina Humana — Banco de Preguntas

Banco de preguntas para preparación al examen de ENCAPS/SERUMS. **400 preguntas únicas** (Tipo A) — 2025-I, 2025-II, 2026-I, 2026-II — con claves oficiales del MINSA.

## Funcionalidades
- **Marcar opciones**: evaluación instantánea (¡Correcto!/Incorrecto) y la respuesta correcta aparece al evaluar.
- **Botón "Desmarcar"**: borra las marcas de la pestaña activa (en un examen solo ese; en "Todas" todas). Las marcas persisten entre sesiones (localStorage).
- **Deep link a ChatGPT**: el botón "Adentrate en esta pregunta con la IA" abre un chat con el contexto de la pregunta y la respuesta correcta (o la que marcaste).

## Archivos
- `serums_banco.html` — banco principal (app).
- `serums_banco_data.js` — datos (`EXAMES`, 400 preguntas).
- `serums-study.html` — página de IA Profesora (opcional).
- `Banco_SERUMS_Medicina_2025-2026.pdf` — PDF oficial de referencia.
- `fuentes_oficiales/` — PDFs de claves oficiales (referencia).
